1. Visão Geral da Integração

O LealCert é uma plataforma completa de venda e gestão de certificados digitais ICP-Brasil (e-CPF e e-CNPJ, tipos A1 e A3). A integração com a Gestão AR permite que todo o ciclo de vida de um pedido — da venda à emissão do protocolo e agendamento do atendimento — ocorra de forma automática e rastreável, sem intervenção manual.

Benefício central: Assim que o pagamento de um pedido é confirmado pelo MercadoPago, o LealCert registra automaticamente a venda na Gestão AR, emite o protocolo e disponibiliza o agendamento — tudo em segundos, sem nenhuma ação manual.
🛒 Produtos suportados
  • e-CPF A1 (arquivo)
  • e-CPF A3 (token/cartão)
  • e-CNPJ A1 (arquivo)
  • e-CNPJ A3 (token/cartão)
⚙️ Configuração necessária
  • API Key Gestão AR
  • Hash do Vendedor
  • Hash da Tabela de Preços
  • Hash de cada produto (certificado)
🔒 Autenticação
  • API Key por header em cada chamada
  • Credenciais armazenadas no banco de dados do painel admin
  • Atualizáveis a qualquer momento, sem redeploy
📡 Endpoints utilizados
  • Comprar — registra a venda
  • EmitirProtocolo — emite o protocolo
  • Pedido — consulta status
  • Agendamento — agenda atendimento
  • Disponibilidade — lista slots

2. Fluxo Completo de um Pedido

1
Cliente realiza o pedido no LealCert

Preenche dados pessoais (CPF/CNPJ), endereço, e-mail, telefone, data de nascimento. Para e-CNPJ: também o CPF e data de nascimento do representante legal.

2
Pagamento via MercadoPago

O LealCert gera uma preferência de pagamento MP. O cliente paga por PIX, boleto ou cartão. O status do pedido fica como aguardando pagamento.

3
Webhook confirma pagamento → LealCert aciona Gestão AR

Ao receber a notificação de pagamento aprovado, o sistema executa automaticamente as etapas 4 e 5 a seguir.

4
Registro da venda na Gestão AR — endpoint Comprar

O LealCert envia os dados do cliente (nome, CPF/CNPJ, endereço, contato) e o Hash do Produto correspondente. A Gestão AR retorna o número do pedido GAR e o Hash da Venda, que são salvos no banco de dados.

5
Emissão do protocolo — endpoint EmitirProtocolo

Com o número do pedido GAR, o LealCert emite o protocolo automaticamente. O protocolo retornado é salvo no pedido e o status avança para "Protocolo Atribuído". Para e-CNPJ, o CPF do representante legal é enviado no campo CPF.

6
Agendamento do atendimento (feito pelo operador ou cliente)

O LealCert exibe os slots disponíveis via endpoint Disponibilidade, com seleção de data e unidade. O agendamento é confirmado via endpoint Agendamento, e os dados ficam registrados no pedido.

7
Atendimento presencial / emissão final

O cliente comparece com o protocolo e documentação. A emissão do certificado ocorre na unidade da AR conforme o agendamento.

5. Agendamento de Atendimento

Após o protocolo emitido, o operador (ou o próprio cliente) pode agendar o atendimento diretamente pelo painel LealCert. O sistema consulta a disponibilidade em tempo real na Gestão AR e confirma o agendamento.

Endpoint Disponibilidade — consulta de slots

Parâmetro enviado Valor
HashVendedor Hash do AR parceiro
DataInicial Data selecionada pelo operador (formato DD/MM/YYYY)
DataFinal Mesmo dia (janela de 1 dia) ou intervalo configurado

Endpoint Agendamento — confirmar agendamento

Parâmetro enviado Valor
HashVenda Hash da venda retornado pelo Comprar
HashLocal Hash da unidade de atendimento selecionada
DataInicial Data e horário de início do slot escolhido
DataFinal Data e horário de fim do slot
IsCliente true (agendado para o cliente)
O agendamento pode ser cancelado pelo painel admin a qualquer momento, via endpoint de exclusão de agendamento da Gestão AR. Os dados do agendamento (local, data/hora, hash do slot) são armazenados no pedido para rastreabilidade.

8. Rastreabilidade — Log de Eventos

Cada pedido possui um histórico de eventos auditável. Todos os passos da integração com a Gestão AR são registrados automaticamente:

Evento Descrição
gar_sale_registered Venda registrada na Gestão AR — inclui número do pedido GAR
gar_sale_error Erro retornado pela GAR no registro da venda — inclui mensagem de erro
gar_protocol_emitted Protocolo emitido com sucesso — número do protocolo registrado
gar_protocol_error Erro na emissão do protocolo — código e descrição do erro GAR
gar_scheduled Agendamento confirmado — data, horário e unidade registrados
gar_schedule_cancelled Agendamento cancelado pelo operador
payment_confirmed Pagamento MercadoPago aprovado — dispara o fluxo GAR

10. Resumo Técnico

ItemDetalhe
Stack do LealCert Node.js 24 + TypeScript · Express 5 · PostgreSQL + Drizzle ORM · React + Vite
Comunicação com GAR HTTP POST com Content-Type: application/json · API Key por campo no body
Trigger do fluxo Webhook do MercadoPago ao receber payment.updated com status approved
Retry / resiliência Erros são registrados no log de eventos; pedido pode ser re-processado manualmente
Ambiente de produção Implantado na plataforma Replit com banco de dados PostgreSQL gerenciado
Segurança das credenciais API Keys armazenadas em banco de dados, nunca em variáveis de ambiente expostas no front
Multi-provedor Sistema suporta Gestão AR e Safeweb — selecionável no painel admin sem redeploy
Resultado para o parceiro Gestão AR: Cada pedido pago no LealCert gera automaticamente um registro de venda, um protocolo emitido e um agendamento disponível — tudo vinculado ao CNPJCPF correto, com dados completos do cliente e rastreabilidade total por log de eventos.
