Listar Horários Disponíveis
Este serviço lista os horários disponíveis de um local de atendimento pela data informada. Caso seja informado a data de hoje, considera o tempo de logística configurado do local.

GEThttps://h-pss.safewebpss.com.br/Service/MicroService/Agenda/Agendamentos/api/Integracao/horarios/{localAtendimentoId}/{data}
Exemplos de uso
C#
Node
var request = require("request");

var options = { method: 'GET',
url: 'https://h-pss.safewebpss.com.br/Service/MicroService/Agenda/Agendamentos/api/Integracao/horarios/{localAtendimentoId}/{data}',
   headers: {'Authorization': '[INFORME_SEU_TOKEN]'} },
};

request(options, function (error, response, body) {
if (error) throw new Error(error);

console.log(body);
});

Parâmetros da Query
#	Atributo	Tipo	Descrição	Obrigatório
#	localAtendimentoId	Int	Id do local de atendimento que será listado os horários	Sim
#	data	Date	Data que será listado os horários do local de atendimento (Caso não seja informado, listará os horários de hoje)	Não
