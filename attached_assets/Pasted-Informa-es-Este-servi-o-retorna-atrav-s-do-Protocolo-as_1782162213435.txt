Informações
Este serviço retorna através do Protocolo as informações da solicitação, local de atendimento e nome da autoridade registro.

GEThttps://h-pss.safewebpss.com.br/Service/MicroService/Agenda/Agendamentos/api/Integracao/informacoes/{protocolo}
Exemplos de uso
C#
Node
    var request = require("request");

    var options = { method: 'GET',
    url: 'https://h-pss.safewebpss.com.br/Service/MicroService/Agenda/Agendamentos/api/Integracao/informacoes/{protocolo}',
      headers: {'Authorization': '[INFORME_SEU_TOKEN]'} },
    };

    request(options, function (error, response, body) {
    if (error) throw new Error(error);

    console.log(body);
    });
